# FakePlayer 假人插件
- 作者: 少司命 羽学
- 出处: TShock官方群816771079
- 这是一个Tshock服务器插件，主要用于：采用淞猫的TrProtocol协议实现假人插件（从少司命的Dummy抄来的）


## 指令

| 语法      |    权限     |        说明        |
| --------- | :---------: | :----------------: |
|  /fake add   | fake.use |   创建单个假人(根据索引自动注册) |
|  /fake del   | fake.use |   移除指定或全部假人（rm）) |
|  /fake me   | fake.use |   让指定或全部假人跟随自己（fm） |
|  /fake list   | fake.use |   列出可显示索引号假人列表（ls） |
|  /fake item   | fake.use |   查询假人背包（i） |
|  /fake set  | fake.use |   设置物品给指定假人同步对应槽位（s） |
|  /fake save  | fake.use |   将自己背包保存为角色文件（sv） |
|  /fake load  | fake.use |   给指定假人加载指定角色文件（ap） |
|  /fake reset | fake.admin |   重置数据、清理角色模板与假人账户ID（rs） |
|  /reload  | tshock.cfg.reload |   重载配置 |

## 使用方法
- 把TrProtocol.dll与假人插件放ServerPlugin文件夹并重启
- 使用指令/fake re 创建一个假人
- 用/fake ap me all 把自身装备复制给假人
- 再用/fake me all 让所有假人跟随自己
- 
- 《如果发现假人站在原地不动》：
- 请使用指令修改假人密码:/user password "假人 00001" 123456
- 可能有插件干扰自动注册，请确保假人与以下密码一致：
- tshock/假人插件/假人/**.json文件中的【密码】
